# Spotify голосом на Станции 1 { #station1-spotify }

Установщик ставит официальное приложение Spotify для Android TV и голосовой мост
к распознаванию Алисы: «Алиса, включи в Спотифай …», стоп, продолжение и перемотка.
Телевизор не нужен: код входа выводится в терминале. Подходит бесплатный аккаунт
[Spotify Free](https://connect.spotify.com/devices/android-tv) с рекламой и его ограничениями.
Для Станции 2 есть отдельный рецепт [Spotify Connect](spotify.md).

**Проверено на:** Станция 1 (tulip), Android 6.0.1 / SDK 23, root AliceBridge,
Spotify TV 1.134.2, аккаунт Free, октябрь 2026. Установка с нуля после полного
удаления — с Windows и командой в терминале Станции, сохранение входа при повторной
установке, код привязки и выход. Голосом: первый трек по русскому и английскому
запросу, стоп, продолжение, перемотка, следующий и предыдущий трек. Работа без HDMI,
перезагрузка с автозапуском моста, воспроизведение из России без VPN.

**Не проверены:** другие модели.

## Что понадобится { #requirements }

- Станция 1 с root и [AliceBridge](../start/root-android.md#station-1).
- Аккаунт Spotify и браузер на телефоне или компьютере для привязки.
- Доступ к Spotify у приложения на колонке. VPN установщик не ставит;
  если доступ ограничен, подключение настраивается отдельно.
- Для установки с Windows — включённый в AliceBridge SSH и штатный OpenSSH.

## Установка { #install }

В **интерактивном терминале колонки** в AliceBridge:

```sh
/system/bin/curl -fL --cacert /system/vendor/quasar/ca-certificates.crt \
  https://raw.githubusercontent.com/Marker284/yandex-station-extended/main/contrib/station1-spotify/install.sh \
  -o /data/local/tmp/install-spotify.sh &&
sh /data/local/tmp/install-spotify.sh
```

Или с Windows, из клона репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File contrib/station1-spotify/install.ps1 -Ip <STATION_IP>
```

`install.ps1` содержит тот же `install.sh`, передаёт его на Станцию по SSH и запускает там.
Ключ берётся из `-Key <SSH_KEY>` или `~/.ssh`; без ключа SSH спросит пароль root.
Дополнительно доступны `-Port <SSH_PORT>` и `-BindAddress <LOCAL_IP>`.

В скрипт встроен мост. Недостающий Spotify TV 1.134.2 скачивает сама Станция с APKPure:
проверяются SHA-256 архива, всех устанавливаемых APK и сертификат базового пакета.
Сертификат сверяется с опубликованным Spotify в
[assetlinks.json](https://open.spotify.com/.well-known/assetlinks.json).
Приложение Spotify не изменяется и не переподписывается.

Устанавливаются базовый пакет, библиотека ARMv7, английские и русские ресурсы,
плотность xhdpi. Один базовый APK без библиотеки не запускается на этой Станции.
При неизвестной версии или подписи существующее приложение сохраняется,
установка останавливается. Повторная установка сохраняет вход и делает резервную
копию файлов моста и автозапуска. Алиса, настройки громкости и сеть не меняются.

## Привязка, состояние и выход { #account }

Получить временный код в терминале, в том числе без HDMI:

```sh
sh /data/station1-spotify/control.sh login
```

Откройте [spotify.com/pair](https://spotify.com/pair), войдите в свой аккаунт
и введите выданный код. Пароль в AliceBridge не вводится. При истечении кода
повторите команду. Генерация кода при первом запуске может занять до минуты.

Состояние медиасессии:

```sh
sh /data/station1-spotify/control.sh status
```

`session: false` означает отсутствие активной медиасессии; это само по себе
не доказывает выход из аккаунта. Проверьте экран приложения или запросите код входа.

Выход и смена аккаунта:

```sh
sh /data/station1-spotify/control.sh logout
sh /data/station1-spotify/control.sh login
```

`logout` просит ввести `YES`, затем удаляет только локальный вход и настройки
приложения Spotify на Станции. Онлайн-аккаунт и его библиотека сохраняются.
Новый аккаунт привязывается новым кодом. Автоматическое подтверждение для своего
скрипта — `logout --yes`.

С Windows эти и остальные команды рецепта передаются параметром `-Command`, например:

```powershell
powershell -ExecutionPolicy Bypass -File contrib/station1-spotify/install.ps1 -Ip <STATION_IP> -Command login
```

Для `logout` подтверждение `YES` спрашивает сам `install.ps1`.

## Голосовые команды { #voice }

Команды после входа в аккаунт:

- «Алиса, включи в Спотифай Daft Punk» — первый трек из поиска.
- «Алиса, включи Daft Punk в Spotify».
- «Алиса, стоп», «Алиса, продолжи».
- «Алиса, следующий трек», «Алиса, предыдущий трек».
- «Алиса, перемотай на 30 секунд» или «…на две минуты назад».

Громкость остаётся обычной командой Алисы.
Общие команды плеера принимаются мостом только после явного запроса Spotify.
При переходе на другой музыкальный сервис режим Spotify сбрасывается.
Реклама и ограничения Free остаются у приложения Spotify.

Мост получает готовое распознавание через локальный IPC Алисы, звук не записывает.
Поиск и запуск первого трека выполняются ссылкой `spotify:search:…`,
управление — через Android-медиасессию приложения Spotify.
Web API, Developer Client ID и отдельный сервер не нужны.
В диагностике моста — счётчики и класс ошибки; текст команд не сохраняется.
При первом запуске приложение может готовить медиасессию несколько десятков секунд.
Команды управления ждут её до 20 секунд. Если сессия так и не появилась,
«стоп» закрывает ожидающий запуска клиент, чтобы музыка не включилась позднее.

## Страна аккаунта и ошибка 14 дней { #country }

Сообщение **Update your location to keep listening** означает ограничение Spotify Free
при использовании за пределами страны аккаунта более 14 дней. Доступ к сайту
или успешная привязка по коду не устраняют это ограничение.

1. Откройте [профиль Spotify](https://www.spotify.com/account/profile/) и проверьте
   **Country or region**.
2. Если страна изменилась, выберите доступный вариант и сохраните профиль.
   Spotify показывает варианты в зависимости от текущего подключения;
   подробности — в [правилах смены страны](https://support.spotify.com/article/country-region-settings/).
3. Проверьте подключение самой Станции. Сеть браузера на ПК, root-терминала
   и приложения на колонке может отличаться. В VPN проверьте, включено ли
   `com.spotify.tv.android` в нужный список приложений и работает ли выбранный профиль.
4. Переподключите приложение после изменения страны или сети:

    ```sh
    sh /data/station1-spotify/control.sh reconnect
    ```

    Если сообщение сохраняется, выполните `logout`, затем `login` и новую привязку.
    Повторный вход не заменяет проверку страны и сетевого выхода Станции.

После смены страны аккаунта в проверке понадобились соответствующее подключение
самой Станции и повторная привязка по коду. Затем короткая проверка из России без VPN
тоже прошла. Это подтверждает работу в момент проверки; ограничение Free на 14 дней
вне страны аккаунта сохраняется. Страну аккаунта и VPN установщик не меняет.

## Повторная установка приложения { #repair }

Если повреждены или отсутствуют части пакета Spotify, загрузите и установите весь набор заново:

```sh
sh /data/station1-spotify/install.sh repair-app
```

Проверяются исходный архив, пять APK и сертификат. Установка поверх той же подписанной
версии сохраняет вход. Команда проверена на Станции 1 с уже привязанным аккаунтом.
Для перезапуска только голосового моста используйте `repair` вместо `repair-app`.

## Отключение и возврат { #uninstall }

```sh
sh /data/station1-spotify/install.sh disable
sh /data/station1-spotify/install.sh enable
sh /data/station1-spotify/install.sh uninstall
```

`disable` останавливает голосовой мост и ставит Spotify на паузу.
`enable` возвращает мост. `uninstall` дополнительно убирает только его строку
из автозапуска AliceBridge. Приложение Spotify, вход и резервные копии сохраняются;
для удаления входа есть отдельная команда `logout`.

## Как это устроено { #how-it-works }

Исходники моста, шаблоны установщиков и сборка находятся в
[`contrib/station1-spotify`](https://github.com/Marker284/yandex-station-extended/tree/main/contrib/station1-spotify).
`install.sh` и `install.ps1` собираются `build.py` из одних исходников;
с JDK 17 и R8 8.3.37 повторная сборка даёт те же файлы байт в байт.

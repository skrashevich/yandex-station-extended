# Spotify TV и голос Алисы на Станции 1

Один файл `install.sh` запускается от root в терминале Станции в AliceBridge:

```sh
sh /data/local/tmp/install-spotify.sh
```

С Windows то же самое выполняет `install.ps1`: в нём встроен тот же `install.sh`,
он передаётся на Станцию по SSH (OpenSSH Windows, root от AliceBridge) и запускается там.
Команды управления передаются параметром `-Command`:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Ip <STATION_IP>
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Ip <STATION_IP> -Command login
```

В файл встроен собственный мост. Отсутствующий официальный Spotify TV 1.134.2
скачивается отдельно; проверяются SHA-256 XAPK, пяти APK и сертификат Spotify.
Поддерживается Станция 1 / tulip, Android 6.0.1 / SDK 23. Подписка Premium для
приложения TV не требуется. Действуют реклама, ограничения аккаунта Free и региона.

[Рецепт, проверенные сценарии и ограничения](../../docs/recipes/station1-spotify.md).
Spotify APK не изменён и не распространяется в этом каталоге.

## Вход и управление

Скрипт установки при первом входе выводит временный код для spotify.com/pair.
Код также можно запросить из терминала без телевизора; пароль вводится только
на сайте Spotify. Смена аккаунта удаляет локальные настройки Spotify, сохраняя
онлайн-библиотеку. Команды:

```sh
sh /data/station1-spotify/control.sh login
sh /data/station1-spotify/control.sh status
sh /data/station1-spotify/control.sh logout
sh /data/station1-spotify/control.sh reconnect
sh /data/station1-spotify/install.sh repair-app
sh /data/station1-spotify/install.sh disable
sh /data/station1-spotify/install.sh enable
sh /data/station1-spotify/install.sh uninstall
```

`logout` требует подтверждения YES; `logout --yes` подходит для собственного скрипта.
`repair-app` скачивает и переустанавливает подписанный набор с сохранением входа.
`uninstall` останавливает мост и убирает его строку автозапуска, сохраняя приложение,
вход и резервные копии. Исходное состояние файлов моста и start.sh сохраняется
в `/data/station1-spotify/backups/` при каждом обновлении.

Голос: «Алиса, включи в Спотифай Кино Группа крови», «стоп», «продолжи»,
«перемотай на 30 секунд». Общие команды принимаются только после запроса Spotify.
Громкостью управляет сама Алиса. Поиск начинает воспроизведение первого результата.
До появления медиасессии при холодном старте возможна задержка.

Мост получает готовое распознавание из локального IPC Алисы, не записывает звук
и не сохраняет текст команд или идентификаторы запросов. Команды плеера выполняются
отдельным app_process, управление — через медиасессию только com.spotify.tv.android.
Метрики, SoundCloud, AirPlay, настройки сети и громкости установщик не меняет.
Web API, Developer Client ID, отдельный сервер и companion APK не используются.

## Воспроизводимая сборка

Нужны Python 3, JDK 17, Android SDK с платформой и build-tools, содержащими D8.
Переменные JAVA_HOME и ANDROID_SDK_ROOT указывают на установленные инструменты.
При отдельном R8/D8 JAR задайте STATION_R8_JAR; опубликованные файлы собраны
с R8 8.3.37 (`com.android.tools:r8:8.3.37` из Google Maven), с ним сборка
воспроизводится байт в байт. Затем выполните:

```sh
python3 build.py
```

Сборка запускает `Check.java` для разбора команд, ограничений IPC, повторных запросов
и распаковки ZIP, затем создаёт DEX для API 23, `install.sh` с фиксированными метками
времени архивов и `install.ps1` со встроенным `install.sh`. Временные файлы — tools/, результат DEX — dist/control.jar.
STATION_SPOTIFY_BUILD_DIR позволяет вынести временные файлы за пределы проекта.
Собственных APK и ключей подписи для этого моста нет.

Файлы `spotify-release.json` содержат версии и контрольные суммы оригинального
пакета. Сертификат Spotify опубликован в assetlinks.json на open.spotify.com.
Обновление версии требует повторной проверки сертификата, всех пяти APK,
воспроизведения и входа. Не заменяйте URL на latest без новых контрольных сумм.

- Установка полного набора пяти оригинальных APK; затем загрузка, проверка и
  повторная установка тем же install.sh repair-app с сохранением привязки.
- Код привязки из терминала, вход, локальный выход и новый вход по коду.
- Первый трек для Daft Punk, Rick Astley и «Кино Группа крови».
- Пауза, продолжение, относительная перемотка через медиасессию.

  выхода системы и UID Spotify — RU, локального VPN нет, позиция воспроизведения растёт.
  Это короткий тест, ограничение Spotify Free на 14 дней за рубежом сохраняется.
- Все проверки воспроизведения — с отключёнными потоками звука и восстановлением
  прежней громкости после остановки.

31.10.2026:

- `install.ps1` с Windows — `status` и полная установка поверх установленного Spotify
  (проверка сертификата, обновление моста, автозапуск без дублей, мост подключён к Алисе).

- Установка с нуля после полного удаления Spotify, `/data/station1-spotify`
  и строки автозапуска — дважды: `install.ps1` с Windows и `sh install-spotify.sh`
  на Станции. Оба раза загрузка XAPK, SHA-256 архива и пяти APK, сертификат,
  установка сессией, запуск моста и вывод кода привязки. После перезагрузки
  мост стартует из автозапуска, воспроизведение и переключение работают.

Владелец Станции подтвердил работу без HDMI и голосовые переходы к следующему
и предыдущему треку. Не проверены другие модели.
